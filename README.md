# MCAF

**MikeGyver Code App Framework**

The open-source ecosystem for building modern, AI-powered Microsoft Power Apps Code Apps.

## Repositories

| Repository | Purpose |
|------------|---------|
| [mcaf-sdk](https://github.com/ekim5sg/mcaf-sdk) | Core application framework |
| [mcaf-intelligence](https://github.com/ekim5sg/mcaf-intelligence) | Provider-neutral AI gateway |
| [mcaf-samples](https://github.com/ekim5sg/mcaf-samples) | Reference applications |

## Vision

MCAF enables developers to build modern Microsoft Power Apps Code Apps using:

- Reusable UI components
- Metadata-driven forms
- Plugin architecture
- Provider-neutral AI
- Enterprise-ready patterns
- Cloudflare Workers AI integration

## Getting Started

Start with **mcaf-sdk**, deploy **mcaf-intelligence**, then explore **mcaf-samples**.
